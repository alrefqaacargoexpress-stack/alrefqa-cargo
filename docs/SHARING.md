# دليل مشاركة مؤسسة الرفكة للشحن

## الوصول إلى المستودع الخاص

شارك رابط المستودع مع المطور المطلوب، ثم امنحه من إعدادات الوصول في GitHub صلاحية تناسب عمله. اختر القراءة للمراجعة والتنزيل، وصلاحية الكتابة فقط لمن سيعدل الكود. تختلف خيارات الوصول حسب نوع الحساب والمستودع؛ لا يُمنح الوصول بمجرد إرسال الرابط.

لا توجد دعوات لمتعاونين تُرسل تلقائيًا ضمن إعداد المشروع. لا تشارك حساب GitHub نفسه أو كلمة مروره أو مفاتيح اتصال قاعدة البيانات.

## تنزيل ZIP

افتح المستودع بعد تسجيل الدخول بحساب مخول، واختر الفرع المطلوب، ثم **Code → Download ZIP**. فك الضغط في مجلد جديد. هذا تنزيل للمصدر عند تلك النسخة، وليس ملفًا جاهزًا للتثبيت على الهاتف ولا نسخة احتياطية للبيانات المشتركة.

بعد التنزيل راجع README. يجب إعداد قاعدة تطوير وخدمات وبيئة منفصلة قبل التشغيل الكامل. لا تستعمل ملفات البيئة أو قاعدة الإنتاج للتجربة.

## تسليم المشروع بطريقة منظمة

أرسل رابط المستودع، اسم الفرع أو معرف النسخة، وصف المهمة المطلوبة، وحدود التعديل. مثال مناسب:

> هذا مستودع مؤسسة الرفكة للشحن الخاص. المطلوب مراجعة الواجهة والمزامنة فقط، دون حذف بيانات أو ترحيل قاعدة الإنتاج أو تغيير الصلاحيات. يرجى إنشاء فرع مستقل وPull Request مع وصف التغيير ونتيجة فحص الأنواع والاختبارات.

يُفضل إجراء تعديلات المطور في فرع مستقل، ثم مراجعتها قبل دمجها في `main`. عندما يكون النشر التلقائي مفعّلًا، قد يؤدي حفظ نسخة جديدة على المستودع الرئيسي إلى نشرها؛ راجع إعداد النشر قبل الدمج.

## ما لا تشمله المشاركة

الملفات تتضمن الكود والأصول والترحيلات، ولا تتضمن اتصال القاعدة الفعلي أو كلمات المرور أو تقارير البيانات الخاصة خارج المستودع. يحتوي تاريخ المشروع وملفات خطته على معلومات عمل داخلية، لذا يبقى خاصًا ولا يُحوّل إلى Public دون تدقيق منفصل.

رفع الكود إلى GitHub ليس نقلًا لبيانات العملاء أو تغييرًا لاستضافة الموقع. تعديلات قاعدة البيانات والصلاحيات وإضافة متعاون أو نشر نسخة جديدة إجراءات منفصلة حسب موافقة المالك.
